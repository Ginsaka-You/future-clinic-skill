# 用实际研究与原问题验证行为

重要方法变更用干净上下文做前向试验。生成者只读原始任务、相应 Skill 与可自行查找的来源；不读修复报告、后来批评、预期答案、评审标准或其他版输出。保持模型、工具、原始输入、资料范围与完整 Markdown 交付要求可比；保存输入、完整输出、实际查阅来源和工具轨迹、模型与时间。保留失败样本，不挑最好的一次。

评审先依据用户原话及有效澄清确定必须回答的判断，再读报告与原始来源。任务对象或成功含义被替换，直接判该项失败；相关性不能靠更多正确事实补偿。检查重要机制是否自主发现，关键主张是否连接做法、条件、反例、证据范围与判断，实现承诺是否得到实际调用入口、默认值与分支范围支持，当前可做的必要查证是否完成，否定性来源判断是否由实际范围、命中正文与读取覆盖支持，片段失败是否被误扩成后段或整体不可读，正文是否直接完整作答。再单独检查独立可读性，不让偏题报告自行定义更容易通过的目标。

对研究过程修订，比较当前版、仅强化末尾复查版和完整修订。材料环境至少包含可检索而非预先给齐的原始来源，生成者须自行发现关键线索；真实开放检索补查实际访问与来源限制，记录资料截止点，避免把新出现材料算成修订收益。覆盖来源作用链、多目标与引用案例层级、根据证据连续查证，并加一项未用于写规则的新题和一个简单回归题。已有指定候选不能重置为泛泛探索；关系、最强替代、未来反馈与换路、未知与反证、原评价范围和责任应保留。

首次报告完成后，在隔离验证中追加无新事实的“继续深入，仍围绕原问题”。比较新增内容：若此时才补出首轮能取得、原目标已经要求的关键依据或判断，核首轮是否过早停止；新事实或真实改变要求不算首次遗漏，无关扩写不算改善。不得向首次生成泄露后续提醒或判断。

有可独立的重要研究方向时，同一修订下比较单 Agent 与按需并行，记录真实调用、分工、来源回查及主 Agent 综合；比较是否找到决策相关线索、解决冲突并提高答案质量，同时如实记录资源与协调成本。不以 Agent 数、篇幅、来源数、自评分、阶段词或包测试证明研究改善。宿主容量或授权限制保留为未测边界，不能伪造并行。

结果含混或出现关键回退才补受影响对照。结论引用具体报告原文和来源，说明改善、保留、退步与未测边界；有限试验不承诺所有未来问题无需追问。包检查只证明结构与身份，同源交付另核正文、摘要及实际文件一致。独立研究试验不是每份普通会诊的固定组织。
