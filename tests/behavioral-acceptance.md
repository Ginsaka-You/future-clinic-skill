# 用本轮判断、实际查证与原问题验证行为

以下行为标准供用户人工核对实际会诊，也用于获准开展的前向试验；文本安装与行为效果分别记证据。重要方法变更用干净上下文做前向试验。生成者只读原始任务、相应 Skill 的入口与研究参考，以及可自行查找的来源；不读修复报告、后来批评、预期论文名、评审标准、本文件或其他版本输出。保持模型、工具、原始输入、资料范围、截止点与完整 Markdown 交付要求可比；保存准确输入、完整输出、实际查阅来源与工具轨迹、模型和时间，保留失败及访问限制，不挑最好的一次。静态包检查或知道批评后的自拟示范不能代替行为证据。

## 项目当前状态、历史结果与推荐强度

用分散在不同日期和文件中的真实项目材料核状态恢复，不预先指定“最新决定”文件、关键转折或预期答案。材料应足以区分早期计划、实际试法与结果、后续决定、角色权限和可用资源；评审据原始正文核首次比较是否采用最新有效状态，旧事实是否带着原时间，资源可用是否被误当作已有效利用，推测和未知是否保留。不能只复述最近一句或罗列背景却继续按旧状态推荐。只追读会改变本轮判断的记录，不要求逐文件全读；确实缺少且会改变判断的用户事实才问，非关键缺口可条件化。

核每条重要推荐与相关旧试法的实质差别：改变了哪个影响结果的条件，依据支持什么，旧失效原因是否仍在。名称、话术、包装或公开入口变化不能自动算突破；不得把某做法有人采用、对方有联络方式或曾接待别人，直接升为当前项目值得首推。历史原因未证实时保留竞争解释，不能用编造的归因衬托新方案。另核条件真实改变的材料：有针对性的资源、输入、关系、激励或实现变化时，允许旧方向重新入选，不把历史失败永久化，也不把单次局部失败扩成整个机制无效。

分别核“做法存在”“适用于当前项目”“值得优先”的论证；来源和措辞都应支持对应强度。证据只到可尝试时，推荐应体现为有理由的查证或小范围验证，说明它如何区分未知、成本与可逆性、反馈后的升降级，不把验证顺序写成效果排序，也不靠末尾“尚未验证”挽救无依据的首推。反向检查不能因为无法保证现实成功而拒绝合理行动，或因不确定就把所有候选等量保留；已有证据支持的差别仍须判断。

用其他领域的既有项目核上述方法可迁移；具体机构、产品、电话、已知排序或本次案例细节不作为通用命中项。指定新问题、简单题与无项目历史的题目应按需要直接完成，不被强制变成长篇历史调查。保留横向独立发现，不因重视历史只重排旧候选；原有保留能力继续按下文核对。

## 开放发现与可交接性

用原始业务问题、真实可用输入及约束开展开放检索，不把期待发现的做法、论文或候选清单喂给生成者。按待检验差异设置现版与候选对照；若确需辨别仅强化末尾复查的作用，再使用不含候选发现方法的末尾对照，不将它变成每次修订的必需版本。关键对照必须包含可检索而非预先给齐的原始来源，保存资料截止点，避免把新出现材料误算成提示收益。旧版可能已正确，不制造基线失败，候选不能靠更长输出证明改善。

评审先按用户原话与有效澄清确定必要判断，再读完整报告与原始来源。检查是否自主发现决策相关的不同判断机制及具体输入实现、完整系统或实践证据；是否从原问题与不同入口找线索，而非只沿首篇论文或熟悉模型补资料。发现的价值在于改变入选、暂缓、条件、比较问题或优先级；只多列名字、算法、引用或页数不能算改善。诊断案例中的已知来源可用于评审回查，不能成为所有任务必须命中的名单；同样相关且有原始依据的其他做法也可能满足责任。

逐个入选方向检查具体主张、输入、关键来源及定位、证据范围、反例、相邻方向关系、共同基线和未决问题。仅将报告与共享原题交给后续研究者，也应能开始一个有边界的问题，知道希望取得什么结果，以及何时继续、收缩、换路或停止。交接只有名称或“继续深入”即失败；不要求本轮完成全部复现或工程实施。共同组件不伪装为竞争方向，缺某一实现输入不误排整个家族，简单规则失败不自动淘汰有具体区分理由的复杂方向，研究价值不冒充效果排名。

对依赖历史／聚合／比较样本的入选方向，另核首次排序已辨清实际取得范围与输出主张：已知对象可查是否被误当完整窗口、其他对象可枚举或总体可用，当前选样是否被误当总体背景？共同评价是否暗加已表达意图、已参与或已取得输入的条件，缩小原题对象并遗漏做法改变需求／参与机会的影响？局部组可以单报，原目标范围及未覆盖部分仍须明确。字段存在不能抵扣查询覆盖；范围未知应限制对应版本与优先级，并保留真实可研究的较弱实现。深入提醒才补出会改变输入资格或排序的边界时，记录为首轮必要遗漏，修复受影响规则并做相称回归；后续正确不能抹去首轮失败。修复后的已知问题回归不冒称新的干净开放首轮。

## 诊断、约束更新与可行动判断

用冻结的多文件异常结果题比较现版与候选。给原题、实际结果、可自行检索的源码／配置／原始记录及截止点，不提前给异常根因、关键参数、应查文件或后来诊断。评审依据原题和原始来源确定首轮必需判断，检查生成者是否自主发现决定归因的竞争解释，取得可区分的来源／生成／传递／消费证据，必要时使用只读复算或隔离探针；按设定不产生输入、生成／传递缺陷、算法结论和现实未知能否分开。只列症状后建议继续查失败；不要求所有题审固定层数、完整复现、业务修复或现场资格证明。涉及整体判断时核覆盖，代表对象不可冒充全体。

用原有方案、可检索的关键比较与已有能力资料，再补一个真实约束，检查是否回读决定性正文，重判每项受影响的具体前提与去留。排除一个实现不能自动排除整个方向，设计维度不同不能用一个标签代替。保留的变体、排低理由、关键接口责任和真实缺少的用户选择应有对应依据；不规定必须选哪个厂商或路线，未经比较宣布收敛即失败。旧报告的意见不作为原始能力证据。

加一个未参与写规则的其他领域多步骤诊断或落地题，核方法是否迁移，而非只记住旧设备、参数或通信名字。另用真正缺证据题检查停止边界：允许资料与合理查证仍不能区分时，说明尝试、缺失、竞争解释、条件结论和最小外部验证；编根因、越权部署或无新信息无限查证失败。

对“后续应查”及“先做A再查B”，逐项核是否属于原题当前必需判断、当时可取得且已授权，以及依赖是否真实。只把新增事实、实施／现场动作、真正不可取得或不影响当前判断的深入工作交后续。设想用户说“按这个做”：第一步若须重做报告声称已定的核心原因、路线或前提，即缺少当前判断；常规现场确认与普通实现细节不倒推成首轮义务。

## 迁移与保留能力

加一项未参与写规则的其他领域新题，核发现入口和方向交接能否迁移；再用指定候选核验与简单题检查是否直接完成原问题，没有被扩成全领域研究或强制完整主路线推演。前次有效的目标保持、来源作用链、默认值和分支范围、多目标与引用案例层级、片段可读性及读取覆盖要求仍须保留，复用未受影响且同条件的证据；涉及改动或出现回退时补受影响对照。

任务对象或成功含义被替换直接判该项失败，更多正确事实不能补偿偏题。核关键主张连接做法、条件、反例、证据与判断；实现承诺由实际入口、默认模式及例外支持；本轮可做的必要查证完成；否定性来源判断有实际范围、命中正文与读取覆盖；单处解析失败没有被推广到后段或整个来源。指定责任、原评价范围、关系、最强替代、必要未来反馈与换路、未知与反证应保留。再单独核独立可读性，不让报告自行定义较容易通过的目标。

首次报告完成后，先冻结完整报告、题面、来源身份、实际读取／工具轨迹、模型与强度，再在同一上下文追加无新事实的“继续深查，仍回答原问题”，不向首轮泄漏提醒或预期原因。若此时才补出原题已需、首轮可得且会改变答案、归因、选路或第一动作的证据，记录首次必要遗漏；新事实、新范围、普通深化与无关扩写不算。首轮已有正确行为保留，后续不覆盖原稿。

有独立重要方向且宿主与授权允许时，同一修订下比较单 Agent 与按需并行，记录真实分工、来源回查、综合与成本。容量或授权限制保留为未测边界，不伪造并行；普通会诊不因此强制组织评测。

## 结论与采用边界

依据具体报告原文和原始来源，同口径说明改善、保留、退步与未测项；原题与冻结资料决定标准，不由候选报告自行降低。结果含混、失败或关键回退时补相称的受影响回归；只有变动或失败确需新干净首轮时才新建，记录理由，既有证据不因总版本名变化全部作废。原始失败保留，已知问题回归与新干净首轮分别标记。

另核反向风险：强制全链审计、所有探索最终选赢家、无限查证、越权实施、简单题变重，或诊断改善却损害横向发现。方向数、命名命中、来源数、自评分、扩写量、阶段词和包测试不能单独证明改善。有限试验不承诺所有未来题全对或无需追问。同源交付另核 Markdown、PDF、摘要、实际身份和正文一致；安装后从正常显式入口核实际读取的版本和行为，不将特殊注入或候选路径采用称作生产入口采用。

若宿主不能提供必需的干净生成上下文，保存候选、真实能力检查和可独立完成的结果，保留未测边界；不得假装遗忘、绕过授权建立执行器、降标或先安装再补关键验收。
