# 行为验证不等于文字匹配

对重要方法变更，给干净上下文实际任务、此 Skill 和最小原始材料，检查生成的完整报告。不要把预期结论、修复理由或上一版好答案放进生成提示。

评审先只读报告，复述用户当前问题、候选关系、推荐理由、第一反馈与后续换路，再对照原始材料核对遗漏、事实范围、最强替代与决定性反证。明确点名的候选须保留适当验证责任。无法从报告本体复述而只能靠聊天补充的，不能算改善。

重要回退可用同模型同材料的前后对照，并增加不同领域、含共用能力与条件分支的案例。记录具体原文、改善、退步及未测边界；不以字数、阶段词、固定分支数、链接数或自评分代替判断。保留失败样本，不只交最好的一次。

独立调用仅在宿主允许且授权覆盖时使用，不把它变为每份普通会诊的固定 Agent 工作流。
